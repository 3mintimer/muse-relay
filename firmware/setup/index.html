ATOM S3 設定

Muse Relay

ファームウェアを書き込んだ ATOM S3 を USB で接続します。Chrome または Edge のデスクトップ版で開いてください。

未接続

中継サーバー

サーバーの設定画面で書き出した機器用 JSON を読み込めます。

アプリ用トークンとは別の機器用トークンを設定します。

追加のサーバー認証（任意）

サーバーが追加認証を求める場合だけ入力します。空欄なら現在の設定を変更しません。

Muse Gadget SDK

初回または変更時だけ入力します。保存すると機器が再起動します。

この画面はトークンを USB で機器に渡します。ブラウザーの保存領域やサーバーには送信しません。中継設定だけを変更した場合は、保存後に USB 電源を入れ直します。

Muse アプリの Devices でペアリングし、家庭の Wi-Fi を指定します。確認を求められたら ATOM S3 前面のボタンを短く押します。
