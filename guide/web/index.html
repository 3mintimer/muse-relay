スペースを追加する

  1. 1

    Museへ依頼

    「スペース → 追加 → Museに作成を依頼」

    例・表示形式・操作部品を選び「依頼文を作る」。コピーか下書きへ。

  2. 2

    書き出しを受信

    Museへ送信した後
    「受信を確認 → 更新して受信」

    下書きへの追加だけでは送信しません。

  3. 3

    登録して使う

    受信したスペースの
    「追加 → 完了」

    「並べ替え・削除」で順序変更・登録解除。Museの原本は残ります。

自分の中継を用意する

参考実装を使うか、MuseなどのAIに同じ入出力を実装してもらいます。アプリの再ビルドは不要です。

入口 / アプリ → 中継

依頼ごとのJSON

muse-relay-request-<id>.json

新規依頼だけを処理。音声・画像は別ファイルを参照。

出口 / Muse → アプリ

返信・スペース・プロフィール

g2muse-relay.json

Museの返信に元の依頼IDを付け、アプリが読み取ります。
