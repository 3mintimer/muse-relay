# Muse Relay 0.3.28

- In Settings, choose how often the phone refreshes its location while sharing is on: every 1, 3 or 5 minutes. The default is 1 minute.
- Chat uses the most recent fix from the last five minutes and sends immediately, including when a fix is still pending.

## 日本語

- 設定の「現在地」で、共有中の測位間隔を1分・3分・5分から選べます。初期値は1分です。
- チャットは5分以内に取得した最新の位置を使います。測位中でもすぐに送信できます。
