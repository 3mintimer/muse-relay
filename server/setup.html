Muse Relay — 中継サーバー設定

G2 / スマートフォン→HTTPS 中継←自宅の ATOM S3↔Muse

1接続先

この画面は設定ファイルを作成します。サーバーの公開は利用するホスティングで行います。

起動時にポート番号が変わっても再設定は不要です。接続キーによる認証は必要です。

1行に1つ。Even WebView が Origin: null を送る場合だけ、null を追加します。

ホスティング認証（任意）

ホスティングから追加の接続キーを発行された場合に使います。各端末の接続設定へ含めます。

2音声

Muse の音声処理は追加設定なし。Soniox のリアルタイム文字起こしを使う場合のみ入力します。

このMacの設定ファイルへ保存します。アプリへ渡すのは短時間だけ有効なキーです。

3保存

スマートフォン・ATOM S3・Muse用に別々の接続キーを生成します。保存済みのキーは維持します。

4接続する

スマートフォン

Muse Relay の「接続設定を読み込む」へ貼り付けます。

ATOM S3

ファームウェアのローカル設定に入力します。

Muse

返信・画像・スペースの更新用。Muse の安全な資格情報設定で使います。

中継サーバー

ホスト側で使用する秘密設定ファイルです。Gitへ追加しません。

接続キーをチャットや公開リポジトリへ貼り付けないでください。

node server/index.mjs
